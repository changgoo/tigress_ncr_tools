# Shear-aware gas-column density power spectra

This document describes the mathematical definition, numerical estimator, and
stored products generated by `plot-suite-density-spectrum`. The analysis uses
the face-on (`theta0`) projected total-gas column-density field `nH` from each
simulation.

## 1. Surface-density fluctuation

Let the projected map at time \(t\) be \(\Sigma(x,y,t)\). The `nH` projection
is used directly. A spatially constant conversion from the stored projection
unit to a physical surface-density unit is unnecessary because it cancels in
the normalized overdensity

\[
\delta(x,y,t) \equiv
\frac{\Sigma(x,y,t)}{\langle\Sigma(t)\rangle_A}-1,
\qquad
\langle\Sigma(t)\rangle_A
= \frac{1}{L_xL_y}\int_A \Sigma(x,y,t)\,d^2x .
\]

Thus \(\delta\) is dimensionless and has zero area mean, apart from roundoff.
The implementation removes its discrete mean once more immediately before the
FFT. The archive records the mean of the remapped `nH` map as
`mean_sigma_code`; this remains in the native projection units.

## 2. Shearing coordinates

The local background flow is described by the shear parameter \(q\) and
angular frequency \(\Omega\). Define the residual remap time

\[
t_{\rm remap}
=t-N(t)\frac{L_y}{q\Omega L_x},
\qquad
N(t)=\operatorname{trunc}\left(\frac{q\Omega L_x t}{L_y}\right),
\]

and the dimensionless residual shear slope

\[
s(t)=q\Omega t_{\rm remap}.
\]

Removing an integer number of full \(y\)-box offsets leaves the same
shearing-periodic state while keeping the applied displacement bounded. The
calculation uses the time from each projection header and the effective
`qshear` and `Omega` values from the corresponding run. Runtime
`problem/qshear=...` and `problem/Omega=...` batch-script overrides take
precedence over values in `athinput*`. These quantities must be in the mutually
consistent simulation units for \(q\Omega t\) to be dimensionless.

The map is transformed to periodic shearing coordinates with

\[
g(x,y,t)=\Sigma\bigl(x,y-s(t)x,t\bigr).
\]

For every fixed \(x_i\), this translation is performed spectrally in the
periodic \(y\) direction:

\[
\widetilde g(x_i,k_y)
=\widetilde\Sigma(x_i,k_y)
 \exp[-i k_y s(t)x_i].
\]

This avoids interpolation across the shear-periodic boundary. The normalized
overdensity used by the FFT is formed from the remapped map,

\[
\delta_g(x,y,t)=\frac{g(x,y,t)}{\langle g(t)\rangle_A}-1.
\]

## 3. Fourier modes in the physical frame

The remapped field is periodic and can be expanded using the rectangular-box
wavevectors

\[
k_{x,0}=\frac{2\pi m}{L_x},
\qquad
k_y=\frac{2\pi n}{L_y},
\]

where \(m\) and \(n\) are the signed discrete FFT mode numbers. A mode that is
stationary in the remapped coordinates is a shearing wave in the physical
coordinates. With the remap convention above, its instantaneous physical
wavevector is

\[
k_x(t)=k_{x,0}+s(t)k_y,
\qquad
k(t)=\sqrt{[k_{x,0}+s(t)k_y]^2+k_y^2}.
\]

Consequently, annular bin membership is computed from this physical \(k(t)\),
not from \(\sqrt{k_{x,0}^2+k_y^2}\). This is the essential correction for the
shearing box.

## 4. Discrete power estimator

For grid spacings \(\Delta x\) and \(\Delta y\), and a separable window
\(w_{ij}=w_x(x_i)w_y(y_j)\), the implemented transform is

\[
\widetilde\delta_{mn}
=\Delta x\,\Delta y
 \sum_{i,j} w_{ij}\,[\delta_{g,ij}-\overline{\delta_g}]
 \exp[-i(k_{x,0,m}x_i+k_{y,n}y_j)].
\]

The two-dimensional periodogram is

\[
P_{2\rm D}(k_{x,0,m},k_{y,n})
=\frac{|\widetilde\delta_{mn}|^2}{A_{\rm eff}},
\qquad
A_{\rm eff}=\Delta x\,\Delta y\sum_{i,j}w_{ij}^2.
\]

Because \(\delta\) is dimensionless, \(P_{2\rm D}\) has units of area; the
archive reports `pc^2`. The window-energy normalization makes spectra from
different supported windows comparable. The production suite uses
`window="none"`, so \(w_{ij}=1\) and \(A_{\rm eff}=L_xL_y\).

The one-dimensional spectrum in radial bin \(a\) is the arithmetic mean over
all nonzero discrete Fourier modes whose sheared physical magnitudes fall
inside that annulus:

\[
P_\delta(k_a)
=\frac{1}{N_a}
 \sum_{(m,n):\,k_a^-\leq k_{mn}(t)<k_a^+}P_{2\rm D}(m,n).
\]

`mode_count` stores \(N_a\). An annulus containing no modes is stored as
`NaN`, not zero. Positive and negative Fourier modes are both included.

The default logarithmic bin edges span

\[
k_{\min}=\frac{2\pi}{\min(L_x,L_y)},
\qquad
k_{\max}=\frac{\pi}{\max(\Delta x,\Delta y)}.
\]

These conservative limits use the larger fundamental wavenumber and the
smaller directional Nyquist wavenumber. The representative value of each bin
is its geometric center, \(k_a=\sqrt{k_a^-k_a^+}\). The default is 40 bins.

Optional zero padding evaluates the same windowed transform on a finer Fourier
grid. It does not add spatial resolution or independent modes.

## 5. Dimensionless variance spectrum

With the continuous Fourier convention corresponding to the estimator above,

\[
\langle\delta^2\rangle
=\int\frac{d^2k}{(2\pi)^2}P_{2\rm D}(\boldsymbol{k})
=\int d\ln k\,\frac{k^2P_\delta(k)}{2\pi}
\]

for an isotropic field in the continuum limit. Therefore the stored
dimensionless spectrum is

\[
\mathcal{P}_\delta(k)
\equiv\frac{k^2P_\delta(k)}{2\pi}.
\]

It represents the contribution to overdensity variance per logarithmic
wavenumber interval. The discrete annular estimator and finite box mean that
integrating it is an approximation to the map variance, especially in bins
with few modes.

## 6. Time averages and model colors

The summary figure uses the arithmetic time mean of the spectrum in each
wavenumber bin:

\[
\overline{P_\delta}(k)
=\frac{1}{N_t}\sum_{200\leq t\leq600}P_\delta(k,t),
\]

ignoring only `NaN` entries from empty annuli. This is a mean of instantaneous
power spectra, not the power spectrum of a time-averaged density map.

Models are ordered by decreasing mean `sfr10` over the same interval. Their
line colors use a logarithmic normalization of that mean SFR through the
sequential `plasma` colormap: high-SFR models are yellow and low-SFR models are
dark purple.

## 7. Contents of `density_power_spectra.npz`

Let \(N_m\), \(N_t\), and \(N_k\) denote the numbers of models, sampled times,
and radial bins. The current full-suite defaults give
\((N_m,N_t,N_k)=(32,601,40)\). Models are stored in decreasing mean-SFR order.

| Key | Shape | Meaning |
| --- | --- | --- |
| `model` | `(Nm,)` | Model directory names in SFR-ranked order. |
| `mean_sfr10` | `(Nm,)` | Mean `sfr10` used for ranking and colors. |
| `sfr_time_bounds` | `(2,)` | Time interval used for the mean SFR. |
| `projection_id` | scalar | Projection identifier; currently `theta0`. |
| `field` | scalar | Source projection field; currently `nH`. |
| `target_time` | `(Nt,)` | Requested output times. |
| `time` | `(Nm,Nt)` | Actual projection-header times selected nearest to each target. |
| `k_edges` | `(Nk+1,)` | Radial wavenumber-bin edges in `pc^-1`. |
| `k_centers` | `(Nk,)` | Geometric bin centers in `pc^-1`. |
| `power_delta` | `(Nm,Nt,Nk)` | Annular mean \(P_\delta(k,t)\) in `pc^2`. |
| `dimensionless_power` | `(Nm,Nt,Nk)` | \(k^2P_\delta/(2\pi)\). |
| `mode_count` | `(Nm,Nt,Nk)` | Number of discrete modes contributing to each annulus. |
| `mean_sigma_code` | `(Nm,Nt)` | Area mean of the remapped `nH` projection in native units. |

## 8. Other generated files

The default output directory is
`SUITE/density_power_spectrum_theta0/` and contains:

- `density_power_spectra.npz`: complete numerical archive described above.
- `density_power_spectrum_time_mean.png`: all-model comparison of the
  \(t=200\)--600 mean dimensional and dimensionless spectra.
- `density_power_spectrum.NNNN.png`: one all-model spectrum frame per target
  time when movie rendering is requested.
- `density_power_spectrum_evolution.mp4`: H.264 animation assembled from those
  frames.
- `model_sfr_colors.csv`: rank, model name, mean SFR, exact plasma hex color,
  and SFR averaging bounds.

## 9. Interpretation and quality checks

- The remap and physical-wavevector correction must be used together. A
  standard FFT radius in the remapped coordinates would assign the wrong
  physical \(k_x\) to a shearing wave.
- The full remapped domain is periodic, so no window is needed for the default
  analysis. Windowing is available for deliberately cropped or otherwise
  nonperiodic maps.
- `has_negative_sigma` identifies unphysical source maps but does not censor
  them. It is a narrow negative-pixel diagnostic, not a comprehensive
  corruption detector; positive-valued scale jumps can remain unflagged. A
  positive map mean is sufficient for the code to calculate \(\delta\).
- Fourier remapping preserves periodic structure but cannot repair corrupted
  projection data. Any model rerun requires rebuilding the archive with
  `--overwrite`.
- The annular spectrum compresses directional information. An anisotropic
  two-dimensional spectrum or separate \((k_x,k_y)\) diagnostics would be
  required to study preferred directions directly.
